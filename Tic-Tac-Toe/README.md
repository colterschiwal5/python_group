# Tic Tac Toe
A game where the user can play against the computer or multi-player. Either the 2 users or the user and computer place their assigned letter (x or o) in a grid. The grid can be different sizes, like the standard 3x3 or up to a larger grid size, potentially 5x5 or bigger. The first person to get x's or o's in a straight line across or vertically will win.
